Reinstall kit

Rebuilds the whole Linux setup — Arch, KDE Plasma with the Caelestia Blush look, every program, your configs and fixes — on a fresh install with one script.

working PC— kit-update.sh → ~/reinstall-kit— setup.sh → fresh Arch install

The kit has two scripts that work in opposite directions. kit-update.sh copies the working PC into the kit and never changes the PC. setup.sh reads the kit on a new install and builds everything back. The kit is a public git repo, so cloning it needs no login.

Reinstall in 3 steps

About 15 minutes of archinstall, 20–60 minutes of setup.sh (mostly waiting), then a short to-do list.

Before you wipe anythingOn the old system, run bash ~/reinstall-kit/kit-update.sh one last time so the kit matches the PC.

  1. Install plain Arch

    Boot the Arch USB (Rufus, ISO Image mode, GPT/UEFI). Connect with iwctl for Wi-Fi; Ethernet just works. Run archinstall and follow the checklist. Pick Install, reboot, pull the USB.

  2. Get the kit and run it

    Log in, press Super+Q for a terminal. Clone the kit (no login needed) or copy it from a USB stick or backup drive to ~/reinstall-kit:

    git clone https://github.com/Vymnkoo/reinstall-kit ~/reinstall-kit
bash ~/reinstall-kit/setup.sh

    Type your password (it doesn't show). In the menu, Space ticks, Enter starts. The new look shows fully after the reboot.

  3. Reboot and finish

    Run reboot, then work through ~/reinstall-kit-report.txt. See Still by hand for the usual items.

If setup.sh stops partway (internet drops, AUR down), run it again — it skips everything already done.

Disk configuration

Do not touch the Windows partitionsWindows, its boot partition and any data drives stay as they are. If you're unsure which partition is which, stop and check first.

A dual-boot PC: Manual partitioning, change only the two Linux partitions:

PartitionSizeSet to
Linux bootabout 1 GiBformat, fat32, mount /boot
Linux rootthe restformat, ext4, mount /

A Linux-only PC: "Use a best-effort default layout" with ext4. This wipes that whole disk.

setup.sh

Checks the machine, asks what to install, runs 9 steps, then writes a report.

bash setup.sh                     # do it
bash setup.sh --dry-run           # print what it would do, change nothing
KIT_CHOICES="apps dev" bash setup.sh   # skip the menu (testing)

Before the menu

  • Stops if run with sudo, if the system isn't Arch, or if archlinux.org can't be reached.
  • Asks for your password once and keeps sudo alive in the background.
  • Detects hardware: GPU vendor from lspci, CPU vendor from /proc/cpuinfo, Windows from any NTFS partition. GTX 9xx/10xx and older NVIDIA cards are flagged as too old for nvidia-open.
  • Shows the menu, then a summary to confirm. From here on, output is also logged to ~/reinstall-kit-setup_<date>.log.

The 9 steps

  1. Updating the system

    Turns on multilib and pacman colour, then pacman -Syu with base-devel and git.

  2. Getting paru

    Builds paru-bin from the AUR if missing. The only step that aborts the run on failure.

  3. Graphics + CPU drivers

    Installs each detected hw-* / cpu-* list. An old NVIDIA card is skipped and put on the to-do list.

  4. Installing your programs

    Imports Spotify's signing key directly from Spotify, then installs core, rice, tools and each ticked group (dualboot adds os-prober). Makes /opt/spotify writable for spicetify.

    install_pkgs: whole list in one paru call → on failure, one package at a time

  5. The Caelestia Blush look

    Plasma and the rice packages came with core + rice in step 4. This step builds the rounded-corners KWin effect from extras/kwin-rounded-corners/PKGBUILD (a fixed copy; the AUR recipe was broken).

  6. Putting back your own configs

    Copies configs/home/ into ~, skipping identical files and backing up replaced ones to ~/.reinstall-kit-backups/<date>/. Pauses Plasma's panel while copying so it can't overwrite the restored panels, gives the login splash a picture, runs fc-cache, and enables restored user services with WantedBy=default.target.

  7. Extra tools

    uv tools, Flatpaks from Flathub, and with dev: Claude Code + VSCodium extensions. Applies the Spotify theme; if that fails it goes on the to-do list.

  8. System settings

    Enables NetworkManager, bluetooth, sddm, weekly fstrim. Runs system/plasma-rice/apply-system.sh: blush astronaut login theme, login screen on KWin with your monitor + mouse settings (no black screen on login), no blinking _ console cursor. Adds lines from system/fstab-extra.txt only for drives that exist (an example only, in the public kit). dualboot: os-prober on, clock in local time. creative: joins realtime.

  9. Updating the boot menu

    Rebuilds /boot/grub/grub.cfg; warns if Windows isn't in it yet.

Safe to re-run

Every change goes through run / srun (sudo), which is what makes --dry-run work. A dry run prints a [dry-run] line for every command it skips, including ones whose output is normally hidden (since 1.2.4-alpha). Installed packages, existing group memberships, enabled services and identical files are all checked and skipped.

Package check

Anything installed but not in any list is added to apps.txt — move it to a better group by hand, or to _not-in-kit.txt to leave it out. Anything in a list but no longer installed is only reported; lines are never deleted. Packages archinstall installs live in _archinstall.txt so they aren't flagged.

Upload

Commits are named kit-update YYYY-MM-DD HH:MM. A failed push (offline, gh not logged in) only warns; the next run pushes it.

How do I…

Common changes to the kit.

Add a program

Install it normally, then run kit-update.sh — it lands in apps.txt. Or add the name by hand to the right file in packages/. For a Flatpak, write flatpak:<app id>.

Move a program to another group

Cut its line from apps.txt and paste it into gaming.txt, dev.txt, etc. A game left in apps.txt is skipped when you tick gaming but untick apps.

Remove a program

Delete its line. kit-update.sh lists programs that are in the kit but no longer installed, but never deletes them itself.

Keep an installed program out of the kit

Move its line from apps.txt to packages/_not-in-kit.txt. setup.sh never installs that list, and kit-update.sh stops adding the program back. OBS is there now; install it from Bazaar when you need it.

Save another config

Add its path (relative to ~) to configs/files.txt, then run kit-update.sh. Folders work too.

Bring back an older kit

cd ~/reinstall-kit
git log --oneline              # find the save you want
git checkout <commit> -- configs/home/.config/kwinrc

Test without changing anything

bash ~/reinstall-kit/setup.sh --dry-run

Release a new kit version

Bump KIT_VERSION at the top of setup.sh (MAJOR.MINOR.PATCH-alpha) and add one line at the top of CHANGELOG.md.

Troubleshooting

Messages setup.sh can show, and what to do.

You seeDo this
Don't run this with sudoRun bash setup.sh as yourself; it asks for the password.
No internetConnect with nmtui, then run it again.
Could not install paruCheck internet / AUR status, run it again.
✘ could not install <pkg>Usually an AUR build failing. The rest still installs. Try paru -S <pkg> later, or re-run setup.sh.
could not import Spotify's keyRe-run later; Spotify won't build without it.
could not build the rounded-corners effectWindows just get square corners. Try later: copy extras/kwin-rounded-corners/PKGBUILD to an empty folder and run makepkg -si there.
login screen setup had errorsRead the log; re-run sudo bash ~/reinstall-kit/system/plasma-rice/apply-system.sh $USER. Undo steps are in its header.
Windows not found yetReboot, then sudo grub-mkconfig -o /boot/grub/grub.cfg.
could not mount <drive> nowIt's in fstab; it will try again at boot.
NVIDIA card is too old for nvidia-openInstall the legacy driver by hand (Arch wiki "NVIDIA").
kit-update: could not upload to GitHubRun gh auth login; the next kit-update pushes.
kit-update: not found, skipped: ~/…A path in files.txt doesn't exist on this PC. Remove the line or ignore it.

Something went wrong partway

Run bash ~/reinstall-kit/setup.sh again. It skips everything already installed or set, so a re-run only does what's missing.

A config came back wrong

Your previous version is in ~/.reinstall-kit-backups/<date>/ at the same path.
